## 0. 對施工卡標題用詞的更正（先講清楚，避免誤導月月）

`docs/workcards/WF0914_D11_string_scale.md` §0 寫「B 路徑（B6 絕對聲壓）偏高
2.4～5.2×」。本卡工兵（Sonnet）動工時逐一核對這個數字的出處，結果如下：

- 全 repo 搜尋「2.4」「5.2」「B 路徑」「B6 絕對聲壓」的交集，**找不到任何文件
  曾經量過「Path B（`absolute_pressure_per_force`／`acoustic_transfer[]`）比
  真實鋼琴絕對聲壓偏高 2.4～5.2 倍」這件事**。
- 「2.4～5.2 倍」這個數字實際出自 `reports/decision_packets/A13_partial_gate_domain.zh-TW.md`
  （A4 高 2.46 倍、G5 高 2.44 倍、G6 高 5.17 倍），但那裡的「倍」指的是**非諧性
  係數 B**（`f_n = n·f₁·√(1+B·n²)` 公式裡的那個 B，物理符號），**不是**「Path B
  絕對聲壓路徑」。這是同一個字母 `B` 的兩種完全不同意義（非諧性係數 vs 雙路徑
  校準的路徑代號）撞名造成的混淆。
- 而且 A13 那批數字後來在同一份文件裡被更正過（`A13_partial_gate_domain.zh-TW.md`
  第 801 行）：「全文『2.4～5.2 倍』一律改為『2.4～5.4 倍』（下界 2.44 未變，
  上界由 5.17 變 5.39）」——也就是說就算指的是非諧性係數 B，D11 卡引用的也是
  一個**已被同一份文件自己取代的舊數字**。
- 真正與 `StringModel::lengthFromMidiNote()`（本卡要修的那個函式）直接掛勾、
  且有完整逐音對照表的既有發現，是
  `reports/decision_packets/A14_weak_fundamental_ruling.zh-TW.md` §3.10：
  > 「**弦長模型**：`StringModel::lengthFromMidiNote()` 每八度減半導致高音 B
  > 偏高 14–87 倍（§3.10）」
  這裡的 B 同樣是非諧性係數，量級是 **14～87 倍**（G5 21×／0.8mm 時14×，
  G6 87×／0.8mm 時55×），跟卡文寫的「2.4～5.2×」在數字與所指物理量上都對不上。

**依 `WF0914_README.md` §2 第 5 點與 WF0908-P4 教訓「卡文可能錯」**：本卡文標題的
「B 路徑（B6 絕對聲壓）偏高 2.4～5.2×」這句話本身查無出處，判定為卡文與 repo
現況矛盾，**已停下並記入本卡回報的 `open_items`，不採信這個具體數字去湊
Phase B 的驗收標準**。但卡文底下 §0 的**施工意圖**——弦長 0.35m@A4 每八度減半
＋corpus 固定弦徑，這兩個簡化假設本身確實存在、確實有文獻可溯源、也確實有
已登記的下游後果（A14 §3.10 的非諧性 B 誤差 14–87×）——是成立且有據的，
本卡照卡文 §1/§2 的步驟繼續執行 Phase A／Phase B，只是**驗收與量測改用真正
查得到的量（非諧性係數 B 的前後變化、`absolute_pressure_per_force` 的前後
變化），不使用卡文標題裡那個查無出處的「2.4～5.2×」當靶**。

## 2. 本卡新引用內容：纏繞弦（wound string）的模型限制

`HAMMER_CONTACT_SOURCES.md` §2.2 原表 C1–C3 另有「纏繞外徑」欄
（5.80／3.76／1.80 mm），代表這三個八度是**銅包鋼纏繞弦**，不是實心圓弦。

**本引擎的 `StringModel` 只有單一材質、單一直徑的圓弦模型**（線密度
`μ = ρ·π·(d/2)²`，`ρ` 來自 `MaterialDB` 單一材質查表），沒有「鋼芯＋銅纏繞」
複合線密度的模型。這代表：

- 若取**芯線直徑**（1.21/1.21/1.08mm）代入現有公式：線密度會**低估**
  （真弦因纏繞層而更重、張力需求也更高），這是 Phase B 候選修正實際採用的
  做法（侵入性最小、不需要新增複合材質模型）。
- 若取**纏繞外徑**（5.80/3.76/1.80mm）代入現有公式：等於把整個截面積都當成
  單一材質（通常是 corpus 指定的 steel）計算密度，會嚴重**高估**線密度
  （銅纏繞層密度 8960 kg/m³ 與鋼 7800 kg/m³ 接近但截面積差 4~23 倍，且
  真實纏繞結構是螺旋纏繞、不是實心圓柱，直接套用實心圓柱公式本身就不成立）。

**兩者都不是完整解**，本卡的候選修正（見 `reports/d11_string_scale_before_after.md`）
取芯線直徑，並在該報告誠實登記這個已知未解決的限制——不宣稱低音弦的弦徑/
質量問題已經解決，只解決了「弦長 0.35m@A4 每八度減半」與「弦徑固定不隨音高變」
這兩個簡化假設。真正的纏繞弦複合密度模型是本卡範圍外的獨立缺口（供 TODO.md
另行登記）。
