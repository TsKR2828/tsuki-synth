## 0. 白話

`materials.json` 裡每種材質有三個阻尼數字。其中兩個（`beta_air` 空氣黏滯、
`gamma_radiation` 聲輻射）從專案開始就是「不知道哪來的」——文件裡誠實寫著
「查不到出處」。這是驗證清單上還沒關掉的第一條。

現在查到了：有一份 1988 年的研究，把弦的能量損耗拆成幾個機制，**每一個都
用空氣密度、空氣黏度、弦的半徑與密度、張力這些已知的物理量寫成公式**——
沒有任何需要「配」的係數。也就是說，這兩個數字不必再查表，**可以直接算**。

但有一個麻煩：**現行程式假設空氣損耗跟頻率的平方成正比，而物理推導出來
不是平方。** 所以這不是「把數字換掉」就好，是要改公式的形狀，會動到聲音。

還有一個要先講清楚的：這份研究是**弦**的。舌鼓（梁）和鑼（板）不適用。

## 2. Cuesta & Valette 模型（**文獻，零自由參數**）

以豎琴／大鍵琴弦的實測衰減時間為基礎，把品質因數拆成三項：

```
Q⁻¹ = Q⁻¹_air + Q⁻¹_visc + Q⁻¹_disl
```

```
Q⁻¹_air  = (ρa/ρ) · [ √2/M + 1/(2M²) ] ,     M = (r/2)·√(ω/μa)

Q⁻¹_visc = 0.003 · E · ρ · π² · r⁶ · ω² / (4T²)

Q⁻¹_disl = 1 / 18000
```

| 符號 | 意義 | 單位 |
|---|---|---|
| `ρ` | 弦材料密度 | kg/m³ |
| `r` | 弦半徑 | m |
| `T` | 弦張力 | N |
| `E` | 弦材料楊氏模數 | Pa |
| `ρa` | 空氣密度（論文用 **1.225**） | kg/m³ |
| `μa` | 空氣**運動**黏度（論文用 **1.619 × 10⁻⁵**） | m²/s |
| `ω` | 角頻率 2πf | rad/s |

**每一個量 TsukiSynth 都已經有**（`ρ`、`E` 在 `materials.json`；`r`、`T`
在 `StringModel`；`ρa`、`μa` 是空氣的物理常數）。

**注意 `Q⁻¹_disl = 1/18000` 是唯一的純數字常數**，來自該研究對位錯
（dislocation）損耗的實測擬合；原文說明熱傳導損耗與位錯損耗在量測資料上
無法區分，且頻率無關的位錯項擬合得一樣好，故後續理論研究採用前者以求簡潔。

**這一段的重要含義**：原研究檢視了**四個**機制，只有**兩個**不可忽略——
**空氣黏滯**（低頻主導）與**內部摩擦**（高頻主導，含黏彈性、熱傳導、位錯）。
**細弦的聲輻射不在其中。**

### 2.1 轉成 T60

`Q = π f τ`（τ 為振幅時間常數）⇒ `T60 = ln(1000)·Q/(π f)`，故

```
1/T60 = π·f / (ln(1000) · Q)      ln(1000) = 6.907755278982137（既有常數）
```

## 3. 頻率次方：**與現行形式對不上**（本文件最關鍵的發現）

把 §2 各項代入 §2.1：

| 機制 | `Q⁻¹` 的 ω 次方 | **`1/T60` 的 f 次方** | 現行對應項 |
|---|---|---|---|
| 空氣黏滯 `√2/M` 部分 | ω^(−1/2) | **f^(+1/2)** | — |
| 空氣黏滯 `1/(2M²)` 部分 | ω^(−1) | **f⁰（常數）** | — |
| 黏彈性 `Q⁻¹_visc` | ω^(+2) | **f³** | — |
| 位錯 `Q⁻¹_disl` | ω⁰ | **f¹** | 形式上同 `eta·f/2.2` 與 `gamma_radiation·f` |
| **現行 `beta_air·f²`** | — | f² | **推導中沒有任何一項是 f²** |

**也就是說：現行把空氣黏滯寫成 `f²`，與第一原理推導出的 `f^0.5 + 常數`
不一致。** 這解釋了為什麼那 42 個數字一直找不到出處——**它們是為了一個
物理上沒有對應的函數形式而存在的擬合值。**

同時，現行的 `gamma_radiation·f`（標為「聲輻射」）在形式上等同於位錯項；
但依 §2 的原文，**細弦的聲輻射本來就可忽略**，這一項的物理標籤對弦而言
很可能是錯的——它實際承擔的是內部摩擦裡的位錯／熱傳導部分。

## 4. 數值核對（本文件計算）

### 4.1 重現論文自己的參數（大提琴 D 弦，剛性台架兩端固定）

`ρ = 5535`、`r = 4.55×10⁻⁴`、`T = 147.7`、`E = 2.5×10¹⁰`：

| f (Hz) | Q | T60 (s) | 空氣佔比 | 黏彈佔比 | 位錯佔比 |
|---|---|---|---|---|---|
| 147 | 3629 | 54.3 | 0.797 | 0.001 | 0.202 |
| 1000 | 6787 | 14.9 | 0.511 | 0.112 | 0.377 |
| 4000 | 2817 | 1.55 | 0.102 | 0.741 | 0.156 |
| 10000 | 580 | 0.13 | 0.013 | 0.955 | 0.032 |

**Q 在 1–4 kHz 之間出現極大值**——與原文描述的實測特徵（所有弦在 1–4 kHz
都有明顯的 Q 極大）一致。這是本文件對公式轉錄正確性的驗證。
T60 偏長是預期的：該量測刻意用**剛性非共振台架**，沒有琴橋損耗。

### 4.2 套到 TsukiSynth 尺度的鋼弦（C4，`r = 0.5 mm`、`T = 686 N`、`E = 210 GPa`、`ρ = 7800`）

| 音 | 1/T60 空氣 | 1/T60 黏彈 | 1/T60 位錯 | 合計 T60 (s) |
|---|---|---|---|---|
| C2 (65.4) | 0.00672 | 0.00000 | 0.00165 | 119.5 |
| C4 (262) | 0.01197 | 0.00013 | 0.00662 | 53.4 |
| C6 (1047) | 0.02246 | 0.00830 | 0.02645 | 17.5 |
| C8 (4186) | 0.04343 | 0.53017 | 0.10576 | 1.5 |

**這組數字要小心讀**：C2 的 119.5 s 看起來像又回到 129 s 的老問題，
但**這是「兩端剛性固定、無琴橋」的理論值**，正是 §2 那份量測的邊界條件。
真實樂器要再並上琴橋損耗（`docs/BRIDGE_ADMITTANCE_SOURCES.md`），
C2 並聯後約 4.1 s。**兩份文件互相一致，不衝突。**

### 4.3 那個「頻率無關」的空氣項不是缺的通道

§3 顯示空氣項含一個頻率無關的部分：

```
1/T60_常數 = ρa·μa / (ln(1000)·ρ·r²)
```

鋼弦 `r = 0.5 mm`、`ρ = 7800` 代入 ⇒ **1.47 × 10⁻³ s⁻¹，即 T60 ≈ 679 s**。
在 C4 上它只佔空氣項的 1/7.1。

**所以它救不了低音發散。** `reports/damping_broadband_findings.md` §4 的
結論不變：那個缺口仍然要靠琴橋導納補，不是靠這一項。**本文件不推翻該報告。**

## 5. 這批資料**不涵蓋**什麼

1. **梁與板（舌鼓／鑼）完全不適用。** §2 的三條式子都內建了圓截面弦的
   幾何（`r⁶`、`r²`、弦張力 `T`）。梁與板的空氣黏滯與輻射阻尼要另外找
   ——**本文件未搜尋該題**，不得假設同樣「查得到」。
2. **真正的聲輻射阻尼仍然沒有值。** §2 的模型明確把細弦輻射當可忽略，
   所以它**不能**用來溯源 `gamma_radiation` 的原始物理意義；
   它只能說明「現行那一項在形式上等價於位錯損耗」。
   板／音板的輻射阻尼另見 `docs/EXTERNAL_ANCHOR_SOURCES.md` §3
   （臨界頻率、輻射制度）。
3. **`ρa`、`μa` 是常溫常壓值。** 若日後要做溫濕度相依（見
   `docs/WOOD_ANISOTROPY_SOURCES.md`），這兩個量本身也隨溫度變。
4. **原始論文（Cuesta & Valette 1988）本文件未取得**；§2 的式子逐字轉錄自
   引用它的開放全文（見 §7 #1），該文明列為「given by [7]」的完整算式。
