## 0. 白話：一段話講完

`TODO.md` 有 8 個「驗證缺口」。這一輪去查文獻，結果是：

- **4 個缺口的資料已經齊了**，可以直接開工寫程式（琴橋、弦阻尼、槌頭、木材）。
- **3 個缺口不需要任何資料**，純粹是還沒排到（跨平台、rubber 短音、多音調音器）。
- **1 個缺口卡在外部量測**（揚琴類的實體試體資料），文獻買不到、只能自己量。

最重要的一件事：**這 4 個能開工的缺口不是平行的，有先後順序。**
琴橋導納是其中兩個的前置條件——先做它，另外兩個才有地方接。

## 3. 依賴關係（這一頁最重要的部分）

```
                    ┌─────────────────────────────┐
                    │  #4 琴橋導納 / 共鳴板耦合    │  ← 資料齊，先做這個
                    │  Y∞ = 1/(8√(D·ρs))          │
                    └──────┬──────────────────────┘
                           │ 提供「頻率無關損耗通道」
             ┌─────────────┼──────────────┬──────────────────┐
             ▼             ▼              ▼                  ▼
   ┌──────────────┐ ┌───────────┐ ┌─────────────┐ ┌──────────────────┐
   │ #2 阻尼寬頻化 │ │ #3 輻射/SPL│ │ #6 木材異向  │ │ #1 弦阻尼律      │
   │ (已寫好卡住) │ │ 需要 D     │ │ 需要音板 D  │ │ (可獨立，但會疊加)│
   └──────────────┘ └───────────┘ └─────────────┘ └──────────────────┘

   ┌──────────────────────────┐   ┌────────────────────────────┐
   │ #5 槌頭非線性接觸         │   │ #8 跨平台 / rubber / 調音器 │
   │ 獨立，但會撞 velocity GATE│   │ 完全獨立，不需資料          │
   └──────────────────────────┘   └────────────────────────────┘
```

**三件事必須一起理解**：

1. **#2 已經寫好了但不能收。** 阻尼寬頻化的程式碼躺在工作樹裡，實作 GATE 全綠，
   但它讓 C2 的 T60 從 39 s 變 129 s。原因是舊的常數阻尼一直在兼任琴橋損耗，
   改對之後沒有東西接手。**#4 就是那個接手的東西。**
   （見 `reports/damping_broadband_findings.md` §4）

2. **#1 和 #2 會疊加。** 兩者都改阻尼律。`STRING_DAMPING_SOURCES.md` §4.3 已驗證
   兩份文件的數字互相一致（弦阻尼給的是「兩端剛性固定、無琴橋」的理論值，
   C2 得 119.5 s；並上琴橋後約 4.1 s）。**但同時改兩處會讓歸因變困難**——
   比照 Phase H 的做法，應該分階段、各自留 Rule 10 前後對照。

3. **#5 是獨立的，但風險最集中。** 改力度指數會直接撞 §6 容差表的
   「velocity ×2 電平」判定，2026-08-06 那輪就栽在這裡。

## 4. 建議施工順序

| 順序 | 做什麼 | 理由 |
|---|---|---|
| 1 | **#4 琴橋導納** | 資料最齊、只需一個新參數（音板厚度 h）、解鎖三個其他項 |
| 2 | **#2 阻尼寬頻化收尾** | 程式已寫好，#4 落地後它的低音發散問題自動消失 |
| 3 | **#1 弦阻尼律第一原理化** | 可獨立，但建議排在 #2 之後避免歸因混淆 |
| 4 | **#5 槌頭接觸求解器** | 獨立，但要連同能量正規化層一起設計 |
| 5 | **#6 木材異向** | 等 #4 的音板需要 `D` 時一併進場 |
| 6 | **#3 輻射／SPL** | 最後做；需要 #4 的 `D` 與 #6 的異向 `Dx/Dy` |

不需資料的三項（跨平台／rubber／調音器）可以隨時插隊，不影響上面的順序。

## 7. 這一輪的一個教訓（記錄下來避免重犯）

初版的兩份文件裡寫過「beam/plate 完全沒有文獻」與「揚琴／舌鼓／鑼的外部證據
仍然是零」。**那兩句沒有經過實際搜尋**，是從「搜鋼琴時沒撞見」推論的。
補搜後三種樂器都找到公開量測文獻，兩句都已更正。

**在這個 repo 裡，「沒有資料」和「有資料但不夠好」是完全不同的結論，
不可以用推論代替搜尋**——這與 Rule 1「驗收只認輸出不認敘述」是同一個標準。
`docs/EXTERNAL_ANCHOR_SOURCES.md` §5.1 保留了完整的更正紀錄。
