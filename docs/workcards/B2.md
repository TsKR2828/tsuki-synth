## 4. 公式與常數

本卡**不引入新公式**。唯一要進代碼的是重新量測後的常數值，註解範本（照抄
`CimbalomEngine.h` 現有寫法，只換數字與日期）：

```cpp
// 跨音域響度補償錨點：A4、預設參數（steel / strike 0.3 / Ø0.8mm / Wood 槌）
// 下、以 velocity=0.5 Hertz 錨 τc 預估的攻擊窗能量 Σ modeAttackEnergy()
// （<實際完成日期> B2 收尾重測值：B1 琴橋導納落地後 A4 的 T60 再次縮短，
// 攻擊能量由 0.1497 降為 <新數字>。量測方法與逐步數字見
// reports/gate_outputs/b2_attack_energy_remeasure.txt）
// gain(A4) = 1，中音域維持既有 equal-RMS 校準；
// 見 ModalResonator::loudnessCompensationGain() 與 noteOn() 內 tauCRef 註解。
static constexpr float kCimbalomAttackEnergyRefA4 = <新數字>f;
```

**Rule 4 標註規則**：這個數字的來源類別是「量測」（方法＝用 CLI `--dump-modes`
在 A4／預設材質／預設參數渲染，取得逐 mode 的 frequency/amplitude/decay，套用
`ModalResonator::modeAttackEnergy()` 公式加總），**不是文獻、不是推導**——
註解要寫「量測」，並指到存放量測過程的 GATE 輸出檔路徑。

## 7. 測試要新增什麼

本卡是驗證/收尾卡，不新增物理邏輯，**原則上不新增新的物理判定測試**——
2026-08-10 那批已在 `tests/physics_models_repro.cpp` / `tests/audit_repro.cpp`
加了 eta 寬頻化的測試（每八度減半、`T60=2.2/(f·eta)` 全域成立、
`damping_override` 錨點語意、fail-closed schema），B1 應該已為自己的第四項
加了對應測試（若沒有，那是 B1 卡片的缺口，不由本卡補）。

本卡唯一可能需要新增的是一個**回歸哨兵測試**，防止未來有人改壞 A4 攻擊能量
錨點常數卻沒發覺：

- **檔案**：`tests/physics_models_repro.cpp`（接續現有 eta 測試區塊之後）
- **測試名**（仿現有 `CHECK` 風格字串）：
  `"kCimbalomAttackEnergyRefA4/kChromaticAttackEnergyRefA4 stay in sync with decayTimeForFrequency"`
- **要驗的性質**：用當前 `decayTimeForFrequency` + `modeAttackEnergy` 在
  A4／預設參數重算一次攻擊能量，和三個常數字面值的相對誤差在一個小容差內
  （例如 ±1%，這是測試內部比較用的 epsilon，不是 §6 容差登記表的項目）。
- **反例（必須）**：把其中一個常數字面值故意改成舊值（例如
  `kCimbalomAttackEnergyRefA4` 硬寫回 `0.1609f`），測試必須 FAIL，證明測試
  真的在比對、不是恆真。跑一次確認 FAIL，再改回正確值確認 PASS，兩次結果都
  存到 `reports/gate_outputs/b2_selftest_sentinel.txt`（比照
  `physics_verify.py --selftest`「先證明會抓錯、再證明不誤報」的做法）。

這個測試要不要做由工兵自行判斷合理性，但**若不做，要在完成報告裡寫明原因**
（例如「B1 已在其卡片內做了等價機制」），不能悄悄跳過不提。

## 11. 已知風險與地雷

- **最大地雷**：`BRIDGE_ADMITTANCE_SOURCES.md` §3 自己承認「單一平均 `G` 對
  C3 仍偏短 2.4 倍」——B1 的公式不是萬能解，C3 的 T60 用平均 `G` 算出來可能
  仍然和 Wogram 實測有落差。**這不代表 B2 沒做好**，是 B1 公式本身（量級核對
  而非精確驗證）的已知侷限，§4.1 已寫明。看到「方向對但沒到文獻精確值」不要
  誤判成 B2 失敗去硬調常數。
- **corpus 可能卡在 `summer_m2` 以外的檔案**：B1 的橋耦合項讓所有音符的 T60
  全面縮短（不只低音），中高音域曲目的休止 RMS 邊際檔也可能被牽動
  （前例：2026-08-06 那次 T60/響度改變牽動了 `summer_m2`/`m3`）。跑 corpus
  前不要預設「只有 `summer_m2` 需要看」。
- `kCimbalomAttackEnergyRefA4` 這類常數容易被誤判成「容差」而被自行放寬——
  **它們不是 §6 容差登記表的項目，是量測值，可以改**；但改的方式必須是
  「重新按公式量出來」，不能為了讓某個聽感/GATE 過而回頭調整。

  FAIL，先確認是不是這個已知缺口造成，而不是本卡引入的新問題。
- **歷史教訓**：2026-08-06 那輪因為換了能量預估方法（用實際 τc 而非
