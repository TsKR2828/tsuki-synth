### 4.3 (b) Hertz 接觸峰值力（能量守恆解，非文獻逐字公式）

沿用 B4 已落地的 `alphaForPianoNote(note)`、`logKForPianoNote(note)`
（→ `K(note)`）、`hammerMassForPianoNote(note)`（`HammerImpulse.h`，
**不重新查證，直接呼叫既有函式**）。

**峰值力推導（本卡的推導，非逐字引用）**：對 `F = K·δ^α` 的碰撞過程做
能量守恆——槌頭以初速 `v` 撞上（視為）靜止不動的接觸點，動能全部轉換成
接觸彈性位能直到最大壓縮 `δ_max`：

```
(1/2)·m(note)·v² = ∫₀^δmax K(note)·δ'^α(note) dδ'
                  = K(note)·δmax^(alpha(note)+1) / (alpha(note)+1)

⇒ δmax = [ (alpha(note)+1)·m(note)·v² / (2·K(note)) ]^(1/(alpha(note)+1))

⇒ F_peak(note, v) = K(note)·δmax^alpha(note)
```

**這不是逐字引用的文獻公式，是對 B4 已有的 `F=K·δ^α` 模型做標準能量守恆
代數推導**（跟 `RADIATION_POWER_SOURCES.md` §2.2 推導 `η_rad` 的做法同一
性質，必須在程式碼註解同樣標註「推導自能量守恆，非逐字引用」）。

**已知簡化（必須在文件裡承認，不是新發現）**：這個推導假設槌頭撞的是
「固定不動的接觸點」——真實琴弦在碰撞期間本身也在運動，`Chaigne &
Askenfelt (1994)`（`HAMMER_CONTACT_SOURCES.md` 已引用）用的是**耦合
數值積分**（槌頭與弦的運動方程聯立求解），不是這種簡化的能量守恆
閉式解。這個簡化對**峰值力的量級**通常影響有限（弦的局部有效質量遠小於
槌頭質量），但**不是精確解**，完成報告裡要明寫這個簡化及其理由。

### 4.4 (c) 弦 → 音板真實能量流入功率

沿用 B1 已落地的公式鏈（`BRIDGE_ADMITTANCE_SOURCES.md` §2.1/§2.2，
**不重新查證**）：

```
Y∞ = 1 / (8·√(D·ρs))                      // 音板導納實部（B1 既有）
α_bridge(f) = T·Re(Y) / L                  // 弦端能量損耗率（B1 既有）
W_bridge(f) = 2·α_bridge(f)·E_mode(f)      // 弦流入音板的功率（B6 §4.2 既有推導）
```

`E_mode(f)`（模態能量，真實焦耳）**必須**用 §4.3 算出的 `F_peak` 與弦的
物理模型（質量、張力）重新以真實單位計算，**不是**沿用引擎內部無量綱的
`ModalResonator::Mode::amplitude`——這是本卡與 B6 方案 B 的根本不同之處：
B 是「引擎內部相對量 × 事後校準常數」，C 是「從真實 `F_peak` 重新算一次
真實能量」。這一步的具體積分/離散化方式（脈衝響應譜、還是簡諧近似）
由工兵依 `HammerImpulse.h` 現有的脈衝譜函式（`forceSpectrumMagnitude`
或等效函式）決定，**必須在完成報告裡寫清楚選了哪一種、為什麼**。

### 4.5 (d) 輻射功率

沿用 B6 Phase 1 已落地的 `RadiationModel.h`：

```
σ(f)             // radiationEfficiency()，B6 既有，不改
S                // 音板輻射面積 (m²)，本卡 Phase 0 第 2 項待補
⟨v²⟩(f) = W_bridge(f) · fraction_radiated(f) / (ρ₀·c₀·σ(f)·S)   // 由 §4.4 反解
W_rad(f) = σ(f)·ρ₀·c₀·S·⟨v²⟩(f)
```

（`ρ₀=1.2 kg/m³`、`c₀=340 m/s`，沿用全 repo 統一符號 `ca`。）

`S` 若 Phase 0 推不出，本卡在此環節卡住，見 §12——**不得編一個「大概
1.3 m²」的數字**（`RADIATION_POWER_SOURCES.md` §5 已經這樣警告過一次）。

### 4.6 (e) 1.05 m 處絕對聲壓

球面自由場擴散（標準聲學關係，非文獻逐字引用，但是聲學教科書的通用結果）：

```
I(f) = W_rad(f) / (4π·r²)          // 聲強，r=1.05 m
p(f) = √( ρ₀·c₀·I(f) )             // 遠場平面波近似下 I=p²/(ρ₀c₀)
```

`r=1.05` 固定沿用 `EXTERNAL_ANCHOR_SOURCES.md` §1 的球面量測慣例（與 B6
方案 A/B 用的是**同一個距離定義**，這是唯一跟 B6 共用的常數，其餘完全
獨立推導）。
