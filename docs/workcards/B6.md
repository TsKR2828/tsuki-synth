## 0. 一句話目標

在 B1（琴橋導納）與 B5（木材正交異向）落地之後，於 `--dump-modes` 輸出裡補上

## 4. 公式與常數

### 4.1 已有堅實出處，可直接照抄（Phase 1）

```
臨界（重合）頻率：  fc = ca² / (2π · √(Dx · H))     ca = 340 m/s
```

**R4 標註要求**：`H` 在 `EXTERNAL_ANCHOR_SOURCES.md` §3 原文就是這樣寫的符號，
**該文件沒有明確定義 `H` 是什麼**（很可能是面密度 `ρs = ρ·h`，但不確定，也可能
是 OCR/轉寫自 Ege & Boutillon 論文時的縮寫）。**動工前必須自己去讀
`arXiv:1305.3057`（`BRIDGE_ADMITTANCE_SOURCES.md` 引用清單 #1，已確認開放全文）
原文對應段落，確認 `H` 的真正定義，並在程式碼註解裡寫清楚你查到的定義與頁碼/
段落，不能照抄本卡这個不確定的符號就下去寫程式。** 這是 Rule 4 的字面要求：
公式必須可溯源，含糊的符號不算溯源完成。

```
波導聲學截止：  fga = ca / (2p)     p = 0.13 m（肋距）  ≈ 1.3 kHz
```

這個公式沒有符號歧義（`BRIDGE_ADMITTANCE_SOURCES.md` §4 第 2 點與
`EXTERNAL_ANCHOR_SOURCES.md` §3 一致），可以直接用。`fga` 是**模型有效範圍的
上限**：`f ≥ fga` 時，均質板模型本身失效（音板變成被肋條界定的波導集合），
本卡的輻射模型**不對 `f ≥ fga` 的 partial 給出任何預測**（不是給錯誤值，是
完全不輸出該 partial 的 `acoustic_transfer` 項，讓 specimen_verify 對那個
partial 判 `UNVERIFIED` 而不是拿一個模型本來就不該覆蓋的錯誤值去比對）。

```
音板平均損耗因子：  η ≈ 0.02 ± 0.01（數 kHz 內近似無強系統性變化）
```

來源：`EXTERNAL_ANCHOR_SOURCES.md` §3 / `BRIDGE_ADMITTANCE_SOURCES.md` §2.1
轉引 Ege & Boutillon。**這是音板的「總」損耗因子**（結構內耗＋輻射的合計），
不是輻射本身的份額——見 §4.3 為什麼這個區分很關鍵。

### 4.2 需要工兵動工前自行判斷／查證的部分（Phase 0）

**核心缺口（本卡最重要的發現，寫在這裡是為了讓工兵不用重新踩一次）**：
`fc`／`fga`／`η` 三個數字只描述輻射「骨架」（轉折點在哪裡），**沒有一條現成公式
把「模態的振動能量」直接接成「輻射的瓦特數」**。這條連接公式如果存在，通常長
這樣（標準結構聲學教科書公式，非本卡自行發明，但**本卡撰寫時未逐字核對出處
頁碼**，工兵動工前必須自己查證）：

```
輻射功率：      W_rad(f) = σ(f) · ρ₀c₀ · S · <v²>(f)
輻射損耗因子：  η_rad(f) = ρ₀c₀ · σ(f) / (ω · ρs)
```

`ρ₀ ≈ 1.2 kg/m³`（空氣密度）、`c₀ = 340 m/s`（沿用 `ca`，同一個常數，全 repo
統一符號）、`S` = 音板有效輻射面積、`<v²>` = 音板振動的空間平均均方速度、
`ω = 2πf`、`ρs` = 音板面密度（§4.1 的 `H`，一旦查明定義）。

這兩條式子的出處候選是 `BRIDGE_ADMITTANCE_SOURCES.md` §6 引用清單 #8
（Cremer, Heckl & Ungar, *Structure-Borne Sound*）或 Fahy & Gardonio,
*Sound and Structural Vibration*——**本卡沒有查到這兩本書的原文**（教科書，
非開放取用），只能確認这是結構聲學裡的標準關係式。**Phase 0 的第一件事**就是
想辦法核實這兩條式子（借書、找開放的講義版本、或找 Ege & Boutillon
`arXiv:1305.3057`／`arXiv:1210.5688` 裡是否直接寫出等價形式——他們既然合成過
「輻射制度」的導納曲線，論文裡很可能就有），寫進新文件 `docs/RADIATION_POWER_SOURCES.md`。

**若確認可用**，接下來還缺一個環節：`<v²>(f)`（音板自己的振動速度）本身也沒有
在模型裡被追蹤——B1 目前只算了「弦端損耗率 `α_bridge = T·G/L`」這個**能量流出
弦的速率**，不是音板自己的振動速度。要接上 `<v²>`，Phase 0 還要判斷能不能用
能量守恆的捷徑繞過去：

```
弦流入音板的功率：  W_bridge(f) = 2 · α_bridge(f) · E_mode(f)
輻射佔比：          fraction_radiated(f) = η_rad(f) / (η_i + η_rad(f))
輻射功率（捷徑）：  W_rad(f) ≈ fraction_radiated(f) · W_bridge(f)
```

其中 `η_i`（音板結構內耗，不輻射的那部分）**現有文件完全沒給出跟 `η_rad` 的
拆分比例**——只有一個「總 `η≈2%`」。若 B1 把音板指定成 `materials.json` 裡
既有的某種木料，該材質的 `damping.eta` 欄位或許可以借用當 `η_i` 的近似
（**这是本卡的推導/工程判斷，不是文獻直接給的**，必須在程式碼與新文件裡
明寫「`η_i` 借用材質 `eta` 欄位是本卡的簡化假設，非獨立量測」）。

**這整條「能量守恆捷徑」是否成立、`η_i` 這樣借用是否合理，是 Phase 0 要交出的
判斷，不是本卡替工兵下的定論。**

### 4.3 為什麼「絕對 Pa」需要一個新的校準常數（讀完就懂，不用重新推導）

即使 §4.2 的功率鏈全部成立，`E_mode(f)` 這個「模態能量」目前在整個引擎裡**只有
無量綱的相對值**（`ModalResonator::Mode::amplitude` 是「DC 正規化、無量綱的形狀
係數」，見 `HammerImpulse.h`／`StringModel.h` 註解，本卡 §2 已指出這點要親自
驗證）。**沒有任何地方把這個無量綱值換算成真實的公尺、牛頓或焦耳。**
不管 §4.2 的相對物理鏈條做得多正確，最後算出來的都只是「跟真實 Pa 成正比、
但比例常數未知」的一個相對量。**這個比例常數不能由工兵自行發明**——見 §6
Phase 2 的停下點。

### 4.4 σ(f) 的可用近似式（僅在 Phase 0 查無更精確公式時，作為標註清楚的替代方案）

若 Phase 0 花費合理時間（**建議上限：一次到兩次專注的查證，不是無限期查**）
仍未找到 §4.2 更精確的 `σ(f)` 形狀公式，可以用以下**明確標註為工程近似、非
逐字引用**的替代式：

```cpp
// 輻射效率 sigma(f) 的次臨界頻率近似——來源：緊緻/次波長聲源的輻射阻抗
// 隨頻率平方增長是聲學的通用結果（monopole 輻射電阻 ∝ (ka)^2 ∝ f^2，見
// 任一聲學教科書的小聲源輻射章節，例如 Kinsler & Frey *Fundamentals of
// Acoustics* 或 Fahy *Foundations of Engineering Acoustics* 的緊緻聲源章節）。
// **這不是 Ege & Boutillon 論文逐字給出的公式**，是本卡在查無更精確公式時
// 採用的工程近似，2026-08-?? 經月月確認可接受後啟用。若之後找到論文原始
// sigma(f) 曲線，應優先替換本近似式。
static float radiationEfficiency (float f, float fc, float fga)
{
    if (f >= fga) return -1.0f;               // 模型有效範圍外，呼叫端須排除
    if (f >= fc)  return 1.0f;
    const float ratio = f / fc;
    return juce::jlimit (0.0f, 1.0f, ratio * ratio);
}
```

**這個近似式是否可以用，屬於 §6 Phase 0 的產出之一，不是本卡預先核准的**——
工兵必須先誠實記錄查證過程，查無更好公式時才使用它，並在完成報告裡明寫
「使用了 §4.4 的近似式，理由：查過 A/B/C 沒找到更精確公式」。

## 11. 已知風險與地雷

- **最大地雷：把 §4.4 的近似式或 §6 Phase 2 的任一校準方案當成「已驗證的物理
  結果」寫進文件或 UI。** 這兩者都是本卡承認的工程判斷/待裁決項，不是
  specimen-level 證據。混淆這一點會讓 `ROADMAP_PHYSICS.md` §0 的驗證域聲明
  失去意義。
- **第二大地雷：Phase 2 的絕對校準常數被工兵自己選定並悄悄實作。** 這是本卡
  唯一一個「無論查證多充分都要停下問月月」的點——見 §6 步驟 11 的理由。
- **`imag_pa_n=0.0` 被後續工作誤讀成相位=0° 的物理主張。** §5、§7 已經放了
  文字要求與哨兵測試，但這是最容易被繞過的地方（例如有人在別的卡裡看到
  `acoustic_transfer` 已經有 `imag` 欄位、順手把 `radiation_directivity`
  加進 `model_observables` 想「反正資料都在了」）——回頭看本卡的哨兵測試
  能不能在那種情況下抓到，若抓不到要補強。
- **B1 對音板的損耗因子拆分（`η_i`／`η_rad`）用材質 `eta` 欄位近似，可能物理
  上站不住腳**（`materials.json` 的 `eta` 是為「弦材質內耗」溯源的，不是為
  「音板結構內耗 vs 輻射」這個拆分溯源的，用途借用需要謹慎，§4.2 已標注）。
  若 Phase 0 查證後發現這個借用不合理，不要硬做，回報。
- **`fga` 判斷邊界可能讓 Cimbalom/Piano 高音完全沒有輻射預測**（真實鋼琴高音
  遠超 1.3 kHz `fga`），這代表这些 partial 的 `absolute_spl` 天然停在
  `UNVERIFIED`（因為 `specimen_verify.py` 對缺 `acoustic_transfer` 的 partial
  就是這樣判），**這是誠實的模型侷限，不是 bug**，不要想辦法「補」那些高音的
  預測值去湊覆蓋率。
- **`--dump-modes` 的效能**：`M3` 遺留教訓——`dumpModes()` 曾因字串拼接 O(n²)
  在大曲目上逾時（已用 `MemoryOutputStream` 修過）。本卡若在每個 partial 加
  更多 JSON 欄位，重新確認大曲目（例如 Vivaldi 四季任一大樂章）的
  `--dump-modes` 沒有回歸逾時。
- **歷史教訓（B4 卡片同款提醒）**：任何會改變振幅/能量計算的改動都有機會
  牽動 §6 velocity 判定；本卡理論上不該碰到 render 路徑所以不該有這個風險，
  但如果 Phase 2/4 的某個方案（尤其方案 B 需要新增訊號分接點）不小心引入了
  額外開銷或路徑差異，§8 第 1 條 GATE 會抓到，不要跳過那一步。

  4 不應該在 `S` 未確認合理前繼續往下做。

  「大致合理」這類敘述（Rule 1）。
