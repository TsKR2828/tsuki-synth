## F5 根因調查結果（2026-09-25）

> 卡號 WF0925-F5（研究 lane）。完整報告：`reports/d11_f5_root_cause_2026-09-25.zh-TW.md`；
> 證據：`reports/gate_outputs/wf0925_F5_*.txt`（6 份）。隔離複本建置（`git archive HEAD`＋`patch -p1`），
> 主工作樹的 `src/`／`tools/`／`tests/` 沒有動，容差與門檻沒有動。**本段只補事實，上面的原文與裁決記錄不改，不替月月選。**

**根因（已查清）**：F5 piano 殘餘能量 −63.9 → −58.5 dB 的**全部**變化，來自 C4 基頻（與低次泛音）的 T60 變短：
4.14 s → 2.67 s。T60 變短是因為引擎的琴橋損耗在音高固定時 ∝ 弦徑²×弦長，候選在 C4 把弦徑 0.8 → 1.00 mm、
弦長 0.589 → 0.639 m，琴橋損耗變成 1.70 倍（佔 T60 變化的 102.6%）。F5 用 Hann 窗做一次 FFT，衰減越快、
預測中的基頻漏到 ±3% 帶外的裙邊越多，於是被算成「殘餘」。

| 查證項目 | 結果 |
|---|---|
| 只換 T60（理論層 dump 互換／渲染層 decay_only） | −63.86 → −58.49 dB（重現全部變化） |
| 只換頻率（含非諧性 B）／只換振幅（含槌擊位置、槌頻譜） | 0.00 dB |
| 純理論合成（只用 dump 模態）vs 真實渲染 | 一樣到 0.01 dB → 不是「模型沒預測的能量」，是預測模態自己的窗洩漏 |
| 懷疑 1：泛音因 B 改變滑出 ±3% 窗 | 排除（F5 的帶用同一份 dump 的頻率畫） |
| 懷疑 2：多弦 beating 邊帶 | 不是變化原因（1 弦也退 4.9 dB）；但讓鋼琴底線高約 5 dB、離 −60 只剩 3.9 dB |
| 只換弦長／只換弦徑（渲染層） | −63.1 dB PASS（+0.8）／−59.5 dB FAIL（+4.4） |
| cimbalom F5 | 同機制 −67.3 → −62.3 dB（仍 PASS） |

**重開 A/B 時要知道的新事實**：
- **A（落地）**：在現行規則下（F5 影響 exit code、−60 dB 為 07-23 核准門檻、R2 禁放寬）落地後 `--full` 仍是 FAIL。
  要過 GATE 需要另一個月月裁決：F5 量法要不要改成不把「預測模態自己的窗洩漏」算成殘餘（改 GATE 量法，屬另案，本卡不提數字）。
  另外候選會改整個鍵盤的 T60（D11 前後對照報告沒列）：相對 0.8 mm 樂譜，C4～C7 基頻 T60 短 22～36%、A0～C2 長 15～92%；
  相對 1.0 mm 樂譜，C4～G5 在 −8%～+3%、兩端變長（A0 2.5 倍）。哪邊較像真鋼琴本卡未評估。原有兩個子裁決（纏繞弦、弦徑旋鈕）仍在。
- **B（維持現狀）**：F5 繼續 PASS，但這個 PASS 依賴探針預設弦徑 0.8 mm——**現行引擎**把探針改成 1.0 mm
  （與 `physical_piano.score.json` 相同）就是 −59.5 dB FAIL（0.95 mm 為 −60.6 dB）。
- **參考用中間變體（非建議）**：只採用查表弦長、弦徑維持樂譜值 → F5 −63.1 dB PASS；1.0 mm 樂譜的 B 偏差 G5 9.6×、G6 27.0×
  （完整候選 7.6×／18.7×，現狀 21.6×／86.4×）；代價是 1.0 mm 樂譜中高音 T60 更短（A4 1.72→1.52 s），同樣觸發 R10，未跑其他 GATE。
- 歷史：−60 門檻訂定時（07-23）鋼琴是 −74.7 dB；08-16 起記錄為 −62.6 dB。現行琴橋損耗設 0 的理論合成為 −73.8 dB，
  推測餘裕主要被 08-16 B1 琴橋損耗吃掉（推論，未逐版驗證）。
