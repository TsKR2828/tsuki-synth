## N1　外掛單音就爆音：要怎麼修（Q05 根因出來了）

**白話**：原本以為只有 3 個 preset 會爆。R-a 查出根因是外掛在引擎後面疊了三層「只加不減」的音量，**所有音色都受影響**，使用者自己調也很容易爆：
- Body 共鳴層：濾波器對準每個音的基頻，Body 0.8 在基頻 +15 dB（預設 0.5 也有 +12 dB）。
- 壓縮器自動補償：**27 個 preset 全部都有，就算完全沒在壓也照加**；量依各 preset 的壓縮設定在 +2.0～+7.5 dB（爆音的 7／11／15 號是 +4.5～+5.0 dB）。
- 大空間殘響尾巴：長音時比輸入還大 6～11 dB。

（出處 `reports/wf1002_preset_overshoot_root_cause.zh-TW.md` §0、§7；稽核逐級重算相符。B6 絕對聲壓校準**不是**原因——外掛根本不走那條路。）

| 選項 | 做法 | 改哪些聲音（R10） | 工作量 |
|---|---|---|---|
| A1 | 只調 3 個 preset 的 Output | 只有那 3 個，只改音量 | S |
| **B1** | 拿掉壓縮器的固定自動補償 | 27 個 preset 和所有使用者音色**整體小 2.0～7.5 dB（精確值）**；27 個裡最大聲的剩 −1.85 dBFS。只改音量、不改音色 | S |
| B2 | Body 層做響度正規化（只改音色、不改音量） | 6 個開 Body 的 preset＋所有 Body>0 的音色；需要新的慣例常數 | M |
| B4 | 預設 Output 1.0 → 0.737 | 27 個全部小 2.65 dB | S |
| C | 只維持已做好的 CLIP 指示燈 | 不改 | 0 |

**建議**：**B1**。壓縮器「沒在壓也照加補償」本身就不合常理，拿掉它一次處理全部音色、只改音量，數字是精確算出來的。
B1 之後 preset 11 把 Body 調回預設 0.5 仍會超過（約 +3.8 dBFS）——Body 這層的結構問題可以之後用 B2 另開卡，CLIP 燈已經會提醒。
選了之後照 R10：AI 先出前後對照報告（27 個 preset 的前後峰值表，R-a 已算好大半），你看過再落地。

## N2　FM 殭屍 voice 修法要不要落地（Q09b 的前後對照出來了）

**白話**：外掛用 FM 引擎彈同一個音反覆時，舊的 voice 永遠不結束，一直佔位置、一直被硬切。C2 在隔離副本做了修法和前後對照（`reports/wf1002_fm_envelope_fix_before_after.zh-TW.md`）：

| | 修前 | 修後 |
|---|---|---|
| 月光全曲 FM，同時活著的 voice（不限量時） | 196 顆 | **14 顆** |
| 16 顆 pool 被搶的次數（真程式碼實測） | 798 次 | **0 次** |
| pool 全滿的時間 | 89.9 秒 | 0 秒 |
| CPU（佔即時） | 2.68～2.71% | 2.21～2.23% |
| CLI 8 首位元 | 8/8 | **8/8（完全不變）** |

- 只在「外掛＋FM 引擎＋同音反覆／按著重打／放踏板」時聲音會變；其他引擎、一般彈法位元相同。
- 修前被硬切的 798 次裡有 94 次切的時候音量還在 −10 dB 以內（聽得到的截斷）；修後沒有。
- 一個沒解釋的點：合成測例「同一個音按著重打」修後大了 1.5 dB（推測是同音 voice 相位抵消變少，沒證實）。

| 選項 | 做法 |
|---|---|
| **A** 落地 | 套 `reports/wf1002_fm_envelope_fix.patch`（只改 `src/dsp/Envelope.h` 的 `noteOff()`），整合卡補跑 ctest、HostProbe、pluginval |
| B 不落地 | patch 存檔，主張域維持「FM 同音反覆時舊 voice 不結束」 |

**建議**：**A**。好處明確、CLI 不受影響、還省 CPU。

## N3　F5 量測法要不要改（Q16 研究卡出來了）

**白話**：F5 這條 GATE 要抓「模型沒預測到的多餘能量」，但現行量法（Hann 窗）會把**預測模態自己的頻譜洩漏**也算成多餘能量。衰減越快、漏越多——所以現在鋼琴能 PASS 是靠探針預設弦徑 0.8 mm，換 1.0 mm 就 −59.47 dB FAIL（R-b `reports/wf1002_d11_piano_t60_literature_and_f5_method.zh-TW.md` §4–§5）。

R-b 試了 7 種量法。換窗（M2，Blackman-Harris 等）最單純：
- 乾淨訊號底噪從 −59～−64 dB 降到約 −82～−100 dB（不再被自己的漏墊高）；
- 注入真的多餘能量測試：注入 −60 就量到 −60.4、注入 −70 量到 −70.4——**量得準**；現行 M0 在 1.0 mm 時把 −70 的假訊號量成 −59.1（反而被墊高跨線）。

**但這有 R2 問題**：同一份聲音，新量法的數字一定比較小，所以「會判 FAIL 的情況」變少了，形式上就是放寬。另一個角度是：F5 原本的目的就是抓「沒預測到的能量」，扣掉自身洩漏是**修正量法**，不是放寬容差。這要你判。

| 選項 | 做法 |
|---|---|
| **A** 算修量法，改用 M2（換窗），−60 dB 不動 | selftest 加注入反例；`--full` 重跑；寫 R2 說明。改 GATE 量法、不改聲音 |
| B 算修量法，改用 M8（扣理論洩漏） | 最準，但依賴模型輸出全部正確 |
| C 算放寬，不改 | F5 繼續依賴 0.8 mm 探針（已登記為脆弱點） |

**建議**：**A**。它量真的多餘能量量得比現行準（注入測試證明），而且不比現行量法多依賴模型輸出（兩者都只用預測頻率畫 ±3% 帶）。注意：改了量法**不等於**重開 D11——Q16 維持 D（R-b 也查到 D11 候選並沒有比現行更像真鋼琴）。
