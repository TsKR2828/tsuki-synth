  git checkout-index -a 把目前 staged 的原始碼匯出到 <SCRATCH>/int_dyncrt/src/，只把 CMakeLists.txt 第 82 行改回動態 CRT
  （"MultiThreaded$<$<CONFIG:Debug>:Debug>" → "...DLL"），JUCE 用 junction 指回 repo（用完已拆掉，JUCE 子模組 git status 乾淨）。
  建出來的 CLI 46bd6622…，dumpbin 看得到 MSVCP140／VCRUNTIME140（＝動態）。
