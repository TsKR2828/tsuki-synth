## 3. 低風險觀察（不擋 PASS，交月月／後續卡）
======================================================================
a. Q06 一次性保護的邊角：專案 state 還原成「使用者 preset」後，若 host 從沒回送 program 變更，保護會一直待命；
   使用者之後第一次「從 DAW 的 program 清單選工廠 0 號」會被吞掉一次（再選一次就會載入）。從外掛自己的選單選不受影響。
   以前（使用者 preset 也有 program 編號）沒有這個邊角；但若不保護，host 回送 0 會把還原的使用者 preset 蓋成工廠 0，代價更大。
   要不要改成「保護只在 setState 後短時間內／第一個 processBlock 前有效」，可另開卡。
b. PluginEditor.h 註解說 1.5 s 在「the card's "1-2 s"」內，但 repo 內找不到寫 1–2 s 的卡（裁決包 Q05、UI 規格 §4.14 都沒寫，
   §4.14 寫「亮多久由設計端決定」）。已標 UI 慣例、非 GATE 常數，符合要求；只是出處那半句不可追溯。
c. Q10 載入失敗警告的「原因」是 IRLibrary／validateAndLoadIRFile 的英文訊息，中文介面下會出現中英混排。
d. H7 載入端從「setCurrentProgram 走 PresetManager::loadPreset」改成「把 preset 檔當 DAW state 還原」；
   真實 VST3 內的 loadPreset→applyExtraStateBlock 路徑現在只在 ShadowProcessor（同一份 header）驗。這是 Q06 後 VST3 ABI 下
   唯一可行的做法，工兵在註解寫明；HostProbe 每次多跑約 70 s 的 Q09 串流量測（CI 時間會增加）。
