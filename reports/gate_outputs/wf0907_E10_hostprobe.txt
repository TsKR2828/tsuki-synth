Why "just link PluginProcessor.cpp into HostProbe" doesn't stay small:
  PluginProcessor.cpp defines
    juce::AudioProcessorEditor* TsukiSynthProcessor::createEditor()
    { return new TsukiSynthEditor (*this); }
  As a non-inline virtual override with a `new` expression referencing
  TsukiSynthEditor's constructor, the linker requires that symbol to exist
  (it is reachable via the vtable even if this probe never calls
  createEditor()) -- which requires linking src/PluginEditor.cpp, whose
  compile+link chain drags in juce_gui_basics/juce_gui_extra and every
  editor-side component (LookAndFeel, SpectrumView, etc.). That is a
  materially larger CMakeLists.txt change than this card's declared scope
  (GATE 5: tests/host_probe.cpp + 2 docs only).
