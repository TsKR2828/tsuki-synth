## 0. 一句話白話導讀

這張卡要找「架構外的新方法」把音高量測器自己的誤差壓到 1 cent 以下。找到的方法是
**時域最小平方擬合（NLS）**：不看 FFT 格子，直接把 1.23 秒的音當成
「幾個會衰減的正弦波相加」去反推它們的頻率。

**合成測試上它贏得非常乾脆**——四條合成關卡全過，而且不是低空飛過，是把現行
估計器的誤差砍掉一到三個數量級（開發網格 1.1721c → 0.2868c、hold-out
1.0840c → 0.0816c、增益保真 16.86c → 0.0090c、三弦 course 中心 0.3337c →
0.0064c）。

**但一搬到真實渲染音檔就輸了。** 在產品 GATE 真正走的那條路徑（`stem_verify`
乾聲分軌，給愛麗絲前 300 個事件）它把 **7 顆 PASS 判成 FAIL**（251/13/36 →
244/20/36）；在「強域全綠」30 檔 corpus 上它動了 **9 檔**（5 顆 PASS→FAIL、
3 顆 UNVERIFIED→FAIL、1 顆 PASS→UNVERIFIED），而這個 corpus 記錄在案的
不變量就是「0 FAIL 維持」。

**逐顆查過原因，不是猜的**（§3）：給愛麗絲的鋼琴音只響 0.22 秒，但分析視窗是
1.23 秒——音在視窗中間就被放鍵阻尼掐掉了，**它的包絡根本不是一條指數衰減**，
而 NLS 的模型假設就是指數衰減。擬合出來的時間常數只有 τ≈0.030–0.052 秒，換算
線寬約 26 cents（在 E5）；於是模型挑的第 2、第 3 個「分音」彼此只差 ~20 cents，
**遠遠落在對方的線寬裡面，根本不是可分辨的分音**，只是拿來逼近一個「一個寬的、
非勞侖茲形狀的共振峰」的柔性基底（加進去 R² 從 0.67 升到 0.96，所以 BIC 一直
買帳）。把一個分不開的分解拿去做振幅加權平均，答案就會亂跳：三顆 E5/F5 分軌的
頻帶其實是**單一個寬峰、中心離宣告音高不到 1 cent**（帶內 bin 從 −13 到 +12
cents、相對振幅 0.84–1.00），NLS 卻分別報 −5.04 / −5.21 / +5.07 cents，
而質心報 −0.59 / −0.21 / +0.71 cents。**質心比較接近真值；NLS 不是抓到真的走音，
是把一個共振峰劈成兩半。**

### 這輪最值得留下來的教訓（比估計器本身重要）

`tools/measurement_selfcal.py` 合成的訊號是「指數衰減正弦波相加 + 雜訊」——
**這正好就是 NLS 估計器自己的模型**。所以一個「模型剛好對上」的估計器可以
幾乎是套套邏輯地橫掃全部四條合成關卡，卻在 GATE 真正要判的渲染音檔上比現行
估計器更差。**現行形式的 1-cent 自證門檻，本身不足以認證一個估計器上產品線。**
這跟 C10B 稽核發現的「兩個網格都測不到增益軸」是同一類結構盲點，只是高了一層：
上次盲的是「軸」，這次盲的是「訊號模型」。任何未來的嘗試，**要先讓哨兵語料
帶上放鍵/阻尼段**，否則量到的分數不能拿來當作上線依據。

## 1. 先修正卡上 §0 的前提（實測，不照抄）

卡 §0 說「MIDI 37 的 band 比一個 bin 窄十倍」。這對**onset 偵測**用的
`Spectrogram`（N_FFT=2048 @48 kHz，bin 23.4375 Hz）成立：MIDI 37 的 ±3% band
寬 4.1577 Hz = 0.177 bin。但**音高估計器不用那個 STFT**——它對整段 1.23 s
自己做一次 rfft（bin 0.813008 Hz），所以：

| MIDI | f0 (Hz) | band 寬 (Hz) | 音高估計器 rfft 內的 bin 數 | N_FFT=2048 的 bin 數 |
|---:|---:|---:|---:|---:|
| 36 | 65.4064 | 3.9244 | **4.827** | 0.1674 |
| 37 | 69.2957 | 4.1577 | **5.114** | 0.1774 |
| 48 | 130.8128 | 7.8488 | **9.654** | 0.3349 |
| 60 | 261.6256 | 15.6975 | **19.308** | 0.6698 |
| 69 | 440.0000 | 26.4000 | **32.472** | 1.1264 |
| 100 | 2637.0205 | 158.2212 | **194.612** | 6.7508 |

所以偏差機制不是「比一個 bin 窄」，而是**一個只有 5 根 bin、權重左右不對稱的
頻帶被硬邊界切掉**。MIDI 37 乾淨訊號實測五根 bin 落在
−45.974 / −25.241 / −4.753 / +15.496 / +35.511 cents，權重
0.052 / 0.186 / 0.378 / 0.291 / 0.093，加權平均落在 **−0.9065 cents**——
訊號其實一點都沒走音。完整輸出見證據檔 STEP 1。

## 2. 合成關卡：NLS 候選全過，而且贏很多

四條關卡都用**已批准的同一個 1.0 cent 門檻**（月月 2026-08-30 裁定），沒有
新增任何容差；卡 §1.1 只是把既有的 gain-fidelity 掃描從 informational
升為 GATE 判定條件，並把偏移集合擴成 0 / ±3 / ±5 / ±12 / ±25 / ±40 cents。

| 合成關卡 | 產品估計器（硬邊界質心） | C10C 候選（時域 NLS） | 門檻 |
|---|---:|---:|---:|
| 開發網格（1170 點） | **1.1721 c　FAIL** | **0.2868 c　PASS**（0 拒答） | ≤ 1.0 c |
| hold-out 網格（1040 點，只跑一次） | **1.0840 c　FAIL** | **0.0816 c　PASS**（0 拒答） | ≤ 1.0 c |
| 增益保真（308 格，\|量測−真值\|） | **16.8647 c　FAIL** | **0.0090 c　PASS**（0 拒答） | ≤ 1.0 c |
| 三弦 course 中心（18 格） | 0.3337 c　PASS | **0.0064 c　PASS** | ≤ 1.0 c |
| ±3 c 靈敏度反例 | PASS | PASS | ±1.0 c |

hold-out 依卡 §2 的規定**只跑了一次**，在估計器完全定案之後才跑，跑完沒有再調
任何參數。

方法本身（完整推導在 `measure_pitch_cents_nls()` 的 docstring——**該函式未落地**，
月月 2026-09-10 裁決選 A 後只存於 `reports/c10c_nls_candidate.patch`，`tools/melody_verify.py` 內不存在）：模型 `x(t) = Σ A_k·exp(−t/τ_k)·cos(2π f_k t + φ_k)`，K = 1..3 由
BIC 選；殘差是**模型與資料套用同一個 band 投影之後**的差（由 Parseval，
等價於「帶通後的時域殘差」的 L2 範數）——關鍵在於濾波器對模型與資料一視同仁，
所以濾波器自己的邊緣行為不會變成答案的一部分（那正是 C10B 候選 (d) 被撤回的
缺陷）；A_k/φ_k 是線性參數用 variable projection 直接解掉，只留 2K 個非線性
參數給 `scipy.least_squares`。

模型階數的兩個數字都是**從合成資料量出來的，不是拍腦袋**：
- BIC 用 `n_eff`（未 zero-pad 的帶內 bin 數 ×2）而不是 padding 後的長度——
  用 padding 後長度時開發網格最差誤差是 **12.9143 c**（低音／−60 dBFS 的格點
  把多出來的分音花在帶緣洩漏上），改用 n_eff 之後是 **0.2868 c**。
- K ≥ 2 另外要求 `n_eff ≥ 2 × 4K`。這個 2.0 是掃描出來的（1.5 / 2.0 / 3.0 /
  4.0）：1.5 與 2.0 都能消掉全部假分音格點，3.0 與 4.0 會開始**拒答最低音**
  （MIDI 36 帶內只有約 5 根 bin），2.0 是「拒答數維持 0」的兩個值裡較大的一個。
- 拒答門檻 `R² < 0.5`：合成語料裡所有量對的格點 R² ≥ 0.9928，所有退化格點
  R² ≤ 9.4e-5——中間空了四個數量級，0.5 取在空檔正中間。

### 3.2 逐顆診斷：為什麼候選在這些分軌上會錯（實測，非推論）

把 ev65 / ev86 / ev88 各自重建成「單一事件的乾聲譜」重新渲染、直接看擬合內部
（證據檔 STEP 4）：

| 分軌 | 帶內 bin 分布（cents, 相對振幅） | 擬合 τ | K=1 / K=2 / K=3 的 R² | 選中的分量（cents, τ, 振幅） | 回報值 | 質心 |
|---|---|---:|---|---|---:|---:|
| ev65 F5 | −13.8..+10.6，0.84–1.00 | 0.030–0.047 s | 0.689 / 0.921 / 0.962 | (−20.17, 0.047, 0.186) (+12.34, 0.042, 0.377) (−7.84, 0.030, 1.346) | **−5.04** | −0.58 |
| ev86 E5 | −13.1..+12.4，0.86–1.00 | 0.032–0.051 s | 0.660 / 0.917 / 0.957 | (−20.64, 0.051, 0.243) (−8.54, 0.033, 1.754) (+11.81, 0.046, 0.559) | **−5.21** | −0.20 |
| ev88 E5 | −11.0..+12.1，0.80–1.00 | 0.034–0.052 s | 0.674 / 0.917 / 0.959 | (+8.30, 0.034, 0.782) (−12.17, 0.046, 0.245) (+20.38, 0.052, 0.109) | **+5.07** | +0.71 |

τ ≈ 0.03–0.05 s ⇒ 線寬 1/(πτ) ≈ 6–10 Hz ≈ **16–26 cents**（在 E5/F5）。
被挑出來的分量彼此只差 ~20 cents，**全部落在彼此線寬之內**：這不是三個分音，
是一個寬峰的三項近似。物理原因很直白——譜上這些音的 `duration` 只有
0.215–0.231 秒，分析視窗卻是 1.23 秒，**音在視窗中段就被放鍵阻尼掐掉**，
包絡不是單一指數。對照組（同一首、留在 PASS 的 ev0/ev1/ev2）帶內是漂亮的
單峰、K=1 就有 R² 0.79–0.85，候選也給出 −1.54 / −0.58 / −1.79 c，沒有問題。
